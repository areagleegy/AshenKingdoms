# نموذج بطل اللاعب

يحتوي هذا المجلد الآن على نموذج GLB أولي ثابت باسم `player.glb`.

`res://assets/characters/player/player.glb`

## متطلبات الدمج

- تصدير GLB حقيقي يحتوي شخصية كاملة الجسم، لا صورة أو ملفًا فارغًا.
- أصل النموذج عند القدمين وارتفاع تقريبي 1.8 متر.
- اتجاه الشخصية الأمامي نحو المحور المحلي `-Z`.
- يفضّل أن يكون الهيكل العظمي والتحريك مضمّنين إن كان النموذج متحركًا.
- توثيق مصدر الأصل ورخصته في `docs/ASSET_CREDITS.md` قبل نشره.

النموذج الحالي ثابت ولا يحتوي هيكلًا عظميًا أو حركات؛ بُني إجرائيًا دون أصول خارجية. أعد إنشاءه باستخدام `python3 tools/generate_procedural_player_glb.py`، وافحصه عبر `python3 tools/validate_player_glb.py assets/characters/player/player.glb`. إذا تعذر استيراده، يستمر مسار هيئة Godot المؤقتة مع كبسولة تصادم منفصلة.
