ملفات `plans` و`specs` وثائق تصميم ومراجعة؛ لا تُعد دليلًا على اجتياز ميزات إضافية للاختبار أو وصولها إلى حالة إنتاجية.

## ما الذي تعنيه حالة «متحقق»؟

- نجاح GitHub Actions يعني نجاح الخطوات التي نفذها الـ workflow على commit المحدد فقط.
- نجاح تصدير APK أو Web لا يثبت صلاحية التجربة على جهاز حقيقي أو جاهزية النشر التجاري.
- اختبار ENet المحلي يغطي loopback داخل بيئة CI؛ لا يثبت اتصال الإنترنت العام أو الأمان الإنتاجي أو مصادقة الحسابات.
- لا تُوصف ميزة بأنها مكتملة إنتاجيًا ما لم توثّق متطلباتها غير المنجزة ويجتز اختبار القبول الملائم لها.

## الحفاظ على الوثائق

تُفحص الروابط المحلية في ملفات Markdown عبر `python3 tools/validate_docs.py`. يجب تحديث الروابط عند نقل الملفات، ومراجعة وصف التنفيذ عند تغير المشاهد أو السكربتات أو workflows. تجنّب نسخ قائمة حالة النظام إلى عدة ملفات؛ اجعل هذا الفهرس خريطة تنقل، واحتفظ بالتفاصيل التقنية في الوثيقة المختصة.
