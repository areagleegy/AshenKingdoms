## مصدر الحقيقة ومعنى «متحقق»

- الكود وملفات المشاهد وموارد Godot تحدد التنفيذ الفعلي.
- ملفات سير العمل داخل .github/workflows/ تحدد ما ينفذه CI. اقرأ نتائج التشغيل للـ commit المعني بدل الاعتماد على وصف قديم.
- نجاح تصدير APK أو Web لا يثبت أن اللعبة تعمل على جهاز فعلي أو أن النشر الإنتاجي جاهز.
- اختبار ENet عبر loopback لا يثبت أمان الشبكة العامة أو المصادقة أو الأداء عبر الإنترنت.
- [حالة التنفيذ](PROJECT_STATUS_AR.md) ملخص قابل للتحديث، وليست بديلًا عن الأدلة الأصلية.

## صيانة الوثائق

اتبع [دليل كتابة وصيانة الوثائق](DOCUMENTATION_GUIDE_AR.md). الحد الأدنى للتحقق المحلي هو:

~~~bash
python3 tools/validate_docs.py
python3 tools/validate_free_assets.py
~~~

شغّل فحص الأصول عند تعديل ملفات الأصول أو سجل التراخيص. يجب أن تجتاز الوثائق فحوص الروابط في CI، وأن تصف حدود المنتج دون مبالغة في وصف حالة التنفيذ.
