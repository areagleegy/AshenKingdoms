# خطة اختبارات الذكاء الاصطناعي في AshenKingdoms

هذه الخطة تخص **سلوك الأعداء داخل اللعبة**. وهي منفصلة عن أداة التشخيص الاختيارية `tools/ai_test_diagnostics.py` التي تصنف سجلات CI. لا يتطلب اختبار سلوك الأعداء اتصالًا بمزوّد نماذج لغوية أو مفتاح API.

## تنفيذ آلي في CI

```bash
timeout 45s godot --headless --path . res://tests/enemy_ai_test.tscn
```

يجب أن ينتهي الأمر برمز خروج صفر وأن تكون جميع أسطر `[PASS]` ظاهرة، مع `failures: 0`.

| النوع | السيناريوهات التي يغطيها الاختبار |
| --- | --- |
| الوحدة | تهيئة صحة العدو المحلي، وحدود الضرر والموت للعدو الشبكي. |
| السلوك | التوقف عند غياب الهدف، المطاردة داخل نطاق الكشف، والهجوم عند الاقتراب. |
| آلة الحالات | الخمول ← الدورية، المطاردة ← تمهيد الهجوم ← التبريد ← المطاردة. |
| التكامل | إنشاء مشاهد العدو واللاعب، استخدام مجموعات اللاعبين، استهداف أقرب لاعب حي، وإشارة موت العدو. |
| الانحدار | تجاهل اللاعبين الموتى أو ذوي الصحة الصفرية، عدم تكرار الضربة أثناء التبريد، وإلغاء ضربة خرج هدفها من المدى أثناء التمهيد. |
| الحدود | تجاهل الضرر الصفري والسالب، تصفير الصحة بعد الضرر القاتل، ومنع تكرار حدث الموت. |
| الحركة والتعافي | حركة الدورية والرجوع إلى موضع البداية بعد تجاوز نطاق الارتباط. |

## فحوص إضافية قبل الإصدار

هذه الفحوص **ليست ممثلة على أنها اجتازت CI** بمجرد نجاح الاختبار السابق:

1. **التزامن والسلطة:** تشغيل خادم وعميلين مستقلين، والتحقق من أن الخادم وحده يحرك الأعداء ويطبق الضرر، وأن العميل لا يستطيع فرض حالة AI أو الصحة.
2. **الضغط والثبات:** رفع عدد الأعداء واللاعبين تدريجيًا، ثم تشغيل جلسة طويلة؛ تسجيل زمن إطار الخادم، والذاكرة، وعدد تحديثات الحركة والهجوم.
3. **الشبكة غير المثالية:** اختبار كمون وفقد حزم متدرجين، ثم الانقطاع وإعادة الاتصال؛ التأكد من عدم تكرار الموت أو المكافآت ومن اتساق حالة العدو بعد العودة.
4. **Android فعلي:** الاختبار على جهاز منخفض المواصفات وآخر متوسط المواصفات، والتحقق من حرارة الجهاز، ومعدل الإطارات، واستجابة اللمس واتصال Wi-Fi/LAN.
5. **الإنترنت:** اختبار خادم خارجي حقيقي عبر NAT والجدار الناري، وليس loopback المحلي فقط.

## أوامر مجموعة الاختبارات ذات الصلة

```bash
godot --headless --path . --script res://tests/script_load_smoke_test.gd
godot --headless --path . --script res://tests/gameplay_regression_test.gd
timeout 45s godot --headless --path . res://tests/enemy_ai_test.tscn
timeout 45s godot --headless --path . res://tests/network_combat_smoke_test.tscn
bash tools/test-network-loopback.sh
python -m unittest discover -s tools -p 'test_ai_test_diagnostics.py' -v
```

- اختبار سلوك العدو يختبر قواعد AI داخل Godot باستخدام أهداف اختبار ثابتة، ولا يستدعي نموذجًا خارجيًا.
- اختبار التشخيص في Python يفحص مصنّف الأخطاء ومجموعة سجلات معلّمة. تشغيله لا يثبت دقة كل نوع خطأ ممكن.
- لا تعتبر بناء APK أو اجتياز اختبارات headless بديلًا عن الاختبار على هاتف حقيقي.
