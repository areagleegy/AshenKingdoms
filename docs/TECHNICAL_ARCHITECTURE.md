# البنية التقنية

## الحالة الحالية

أصبح المشروع نموذجًا أوليًا قابلًا للتحريك: شخصية CharacterBody3D، أرضية بتصادم، تحكم لوحة مفاتيح على الحاسوب، أزرار لمس، وكاميرا منظور ثالث قابلة للدوران. لا توجد بعد أنظمة قصة أو قتال أو مهام أو حسابات أو مزامنة متعددة اللاعبين مكتملة.

## التقنيات

- Godot 4.6 stable وGDScript.
- Compatibility renderer كبداية للأجهزة المحمولة والمتصفحات.
- Android APK تجريبي وWeb export.
- Linux headless خادم مستقبلي؛ ليس خدمة استضافة مضمنة.

## حدود المسؤولية المقترحة

- Client: الرسم والكاميرا والإدخال وواجهة المستخدم والصوت.
- Shared gameplay: قواعد الحركة والقتال والمهام والمخزون.
- Dedicated server: سلطة حالة الجلسة والتحقق من الحركة والضرر والمكافآت وتوزيع الحالة.
- CI: استيراد المشروع وتصدير Web وAndroid وحفظ نواتج البناء كـ Artifacts.

## مبادئ الشبكة

1. الخادم هو المرجع لصحة اللاعبين والضرر والمخزون والمكافآت.
2. لا تثق في الضرر أو العملات أو إكمال المهام المرسلة من العميل دون تحقق خادمي.
3. ابدأ باختبار لاعبين اثنين في ساحة صغيرة.
4. اختبر التأخير وانقطاع الاتصال قبل توسيع عدد اللاعبين.
5. لا تضع الأسرار أو رموز الوصول في المستودع العام.
