# البنية التقنية

## الحالة الحالية

المستودع يحتوي الآن على نموذج أولي قابل للعب مبني من عقد Godot وموارد GDScript دون أصول فنية خارجية. يشمل النموذج الحركة والكاميرا من منظور الشخص الثالث، القفز والركض، قتالًا أساسيًا، أعداء يطاردون اللاعب، الصحة، جرعات الشفاء، الخبرة والمستويات، مهمة واحدة، وملف حفظ محلي بصيغة JSON.

هذا ليس إصدارًا إنتاجيًا؛ يتضمن حوارًا تجريبيًا واحدًا وشخصية NPC واحدة. توجد ساحة ENet منفصلة بمزامنة خادمية للحركة والقتال والصحة والخبرة ومهمة قتل تجريبية. لا تزال المعدات المتقدمة والقصة الواسعة والحسابات والحفظ الشبكي الدائم ومزامنة الجرد والحوار بحاجة إلى تطوير.

## التقنيات

- Godot 4.6 وGDScript.
- Compatibility renderer للأجهزة المحمولة والمتصفحات.
- Android APK تجريبي وWeb export عبر GitHub Actions.
- Dedicated server: خادم ENet تجريبي يعمل headless، وليس خدمة إنتاج عامة أو استضافة دائمة مضمونة.

## توزيع المسؤوليات

- scripts/core/main.gd: تهيئة ساحة اللعب الفردي وربط المكونات والأحداث والحفظ.
- scripts/core/network_manager.gd وscripts/networking/: إدارة جلسة ENet وساحة الشبكة ومزامنة الحركة والقتال والتقدم التجريبي.
- scripts/player/: حركة اللاعب والكاميرا والهجوم.
- scripts/enemies/: سلوك عدو مطارد وهجوم قريب.
- scripts/components/: الصحة والجرد القابل لإعادة الاستخدام.
- scripts/core/progression_manager.gd: نقاط الخبرة ورفع المستوى.
- scripts/core/quest_manager.gd: تتبع هدف المهمة ومكافأتها.
- scripts/ui/hud.gd: HUD والتحكم باللمس وقائمتي الإيقاف والجرد.
- scripts/core/save_system.gd: حفظ واسترجاع JSON داخل user://savegame.json.

## التحكم

- الحركة: WASD أو الأسهم.
- القفز: Space.
- الركض: Shift.
- الهجوم: زر الفأرة الأيسر.
- الحقيبة: I أو Tab.
- الإيقاف: Esc.
- حفظ سريع: F5.
- تحميل سريع: F9.

على Android تُعرض أزرار لمس للحركة والهجوم والقفز والركض، ويمكن سحب الإصبع لتدوير الكاميرا.

## مبادئ قبل التوسع

1. الخادم هو المرجع لصحة اللاعبين والضرر والمخزون والمكافآت عند تنفيذ اللعب الجماعي.
2. لا تثق في الضرر أو العملات أو إكمال المهام القادمة من العميل دون تحقق خادمي.
3. افصل تعريفات العناصر والمهام عن قواعد اللعبة مع توسع المحتوى.
4. لا تضع أسرارًا أو مفاتيح توقيع Android في المستودع العام.
5. سجل رخصة كل نموذج أو خامة أو صوت أو خط جديد في docs/ASSET_CREDITS.md.


## نظام الحوار والشخصيات

- مجلد scripts/dialogue يحتوي موارد DialogueAction وDialogueChoice وDialogueNode وDialogueGraph وإدارة محلية في Autoload باسم DialogueManager.
- scripts/npc/npc.gd يقدم NPC بنطاق تفاعل وعلامة اسم.
- scripts/player/interaction_detector.gd يختار أقرب NPC ويعرض زر التفاعل على الهاتف.
- scripts/ui/dialogue_ui.gd وscenes/ui/DialogueUI.tscn يقدمان نصًا متدرجًا بالكتابة واختيارات قابلة للنقر، مع حجب قائمة الإيقاف أثناء الحوار.
- كل آثار الحوار تمر عبر DialogueManager._apply_effects(). عند إدخال اللعب الجماعي يجب أن يصبح هذا المسار طلبًا يتحقق منه الخادم قبل منح الخبرة أو العناصر أو بدء المهام.
- أعلام الحوار تحفظ داخل بيانات الحفظ تحت مفتاح dialogue.flags.
