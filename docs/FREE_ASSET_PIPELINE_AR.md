# دليل مسار الأصول المجاني — ممالك الرماد

## الهدف

هذا المسار يربط ملفات الفن والصوت والفيديو داخل مشروع Godot 4.6 دون API مدفوع أو رصيد توليد أو اتصال شبكة مطلوب وقت التشغيل. الأدوات الخارجية تُستخدم على الجهاز، ثم تُستورد الملفات الناتجة محليًا إلى المجلدات المحددة.

## حالة الربط في المستودع

- إضافة المحرر: addons/ashen_free_asset_pipeline/ — تعرض جردًا للأصول وتفتح المجلدات.
- سجل التراخيص: assets/asset_manifest.json — مطلوب لكل ملف أصل بصري أو صوتي أو فيديو.
- أداة التحقق: tools/validate_free_assets.py — Python قياسي فقط، ولا تنزّل أصولًا أو تتصل بالإنترنت.
- GitHub Actions يشغّل فحص السجل ضمن التحقق الآلي.
- لا تتضمن هذه الدفعة نماذج أو مؤثرات أو موسيقى مولّدة، ولا تدّعي وجود أصول لم تُضف فعليًا.

## المجلدات المستهدفة

- assets/characters/ — نماذج اللاعبين والشخصيات غير القابلة للعب.
- assets/environments/ — المباني والطبيعة والقطع البيئية.
- assets/materials/ — الخامات والصور والقوام.
- assets/audio/music/ — الموسيقى التصويرية.
- assets/audio/sfx/ — أصوات الخطوات والسيوف والقتال والبيئة.
- assets/audio/voice/ar/ — ملفات الحوار العربي المسجل أو المُولّد محليًا.
- assets/video/cinematics/ — المشاهد السينمائية النهائية.
- assets/ui/ — الأيقونات وعناصر الواجهة.

الصيغ التي يتعرف عليها فحص الأصول حاليًا: GLB وglTF وOBJ وDAE، والصور PNG وJPG وJPEG وWebP وSVG، والصوت WAV وOGG وMP3 وFLAC، والفيديو MP4 وWebM. قد تتطلب الصيغ المستوردة إعدادات ضغط مناسبة لـ Android.

## أدوات العمل المجانية

- Blender: بناء النماذج والهيكل العظمي والتحريك واللقطات ثلاثية الأبعاد — https://www.blender.org/
- Krita: الرسم والمفاهيم والخامات ثنائية الأبعاد — https://krita.org/
- Poly Haven: أصول HDRI وخامات ونماذج تحت CC0 بحسب ترخيص الموقع — https://polyhaven.com/license
- Kenney: حزم أصول مجانية؛ راجع ملف الترخيص لكل حزمة — https://kenney.nl/assets
- Audacity: التسجيل وتنظيف الحوار والمؤثرات وقصها — https://www.audacityteam.org/
- LMMS: تأليف الموسيقى محليًا — https://lmms.io/
- Kdenlive: المونتاج وتركيب مشاهد اللعبة — https://kdenlive.org/
- ComfyUI: خيار اختياري لتوليد الصور محليًا على حاسوب مناسب، وليس خدمة سحابية مجانية بلا حدود — https://github.com/Comfy-Org/ComfyUI
- Piper: خيار لتحويل النص إلى كلام محليًا؛ توجد أصوات عربية ضمن توزيعاته، لكن يجب مراجعة ترخيص ملف الصوت نفسه واختبار جودة العربية قبل الاعتماد — https://github.com/networkedaudio/piperTTS

الأدوات ليست جميعها مناسبة للتشغيل مباشرة على Android. يمكن توليد الأصول وتحريرها على حاسوب محلي ثم نقل الناتج إلى المستودع عبر Git. لا يلزم اتصال مدفوع أو إدخال مفاتيح API.

## سياسة الترخيص

قبل إضافة أي أصل إلى المشروع، تحقّق من الترخيص الفعلي للأصل نفسه ومن سماح الترخيص بالاستخدام التجاري وإعادة التوزيع. يُفضّل CC0 أو MIT أو CC-BY مع إدراج الإسناد المطلوب. لا تفترض أن جميع الملفات الموجودة في موقع واحد لها الترخيص نفسه.

أضف لكل أصل داخل مصفوفة assets في assets/asset_manifest.json كائنًا بالحقول التالية:

- path: مسار الملف داخل المستودع.
- author: اسم المؤلف أو الجهة.
- source_url: رابط المصدر الأصلي.
- license: اسم الترخيص الدقيق.
- license_url: رابط نص الترخيص.
- attribution: نص الإسناد المطلوب أو بيان موثّق بأنه غير مطلوب.
- commercial_use: true فقط بعد التحقق.
- redistribution_allowed: true فقط بعد التحقق.

رفض الفحص يعني عدم دمج الأصل حتى تُصحح بياناته؛ لا تغيّر قيمة السماح لتجاوز الفحص.

## الاستخدام

من جذر المستودع:

~~~bash
python3 tools/validate_free_assets.py
~~~

لفحص جذر آخر:

~~~bash
python3 tools/validate_free_assets.py --root /path/to/AshenKingdoms
~~~

في Godot 4.6 افتح المشروع وابحث عن لوحة Ashen Free Assets. اضغط «تحديث الجرد» لمشاهدة عدد الملفات المعروفة، أو افتح مجلد فئة لاستيراد الأصول التي جهزتها. بعد نسخ الأصول، راجع إعدادات الاستيراد والحجم والذاكرة على Android.

## ما لا تنفذه الإضافة

الإضافة تنظّم وتعدّ الملفات فقط. لا تقوم بتوليد الصور أو الصوت، ولا تثبّت Blender أو ComfyUI أو أدوات أخرى، ولا تتصل بمواقع خارجية. هذا مقصود لتجنب الرسوم والاعتماد على خدمات الشبكة.
