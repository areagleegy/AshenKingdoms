# إصدار Android التجريبي مع التشخيص الآلي

## الهدف

يوفّر سير العمل `.github/workflows/experimental-android-qa.yml` حزمة APK تجريبية من فرع محدد، مع تقارير اختبارات وتشخيص قابلة للمراجعة. شغّله يدويًا من GitHub Actions على الفرع الذي تريد اختباره.

## ما الذي يفعله؟

1. يهيّئ JDK 17 وAndroid SDK وقوالب Godot 4.6 المطابقة.
2. يستورد المشروع ويشغّل اختبارات الموارد واللعب والانحدار وبطل اللاعب، إضافة إلى اختبارات مصنّف التشخيص.
3. يصدّر APK باسم `AshenKingdoms-Experimental-QA.apk`.
4. يحسب حجم الملف وبصمة SHA-256.
5. ينشئ تقرير JSON وملخص Markdown من السجلات، ويرفع APK والتقارير كسجل Artifacts لمدة 7 أيام.

## تشغيله

1. افتح تبويب **Actions** في المستودع.
2. اختر **Experimental Android QA APK**.
3. اضغط **Run workflow** وحدد فرعًا.
4. اترك `ai_diagnose=false` للتشخيص المحلي الافتراضي، ثم ابدأ التشغيل.
5. نزّل Artifact باسم `ashen-kingdoms-experimental-android-qa` بعد انتهاء المهمة وافحص التقرير والبصمة قبل تثبيت APK.

## ضوابط الذكاء الاصطناعي والسلامة

- القواعد المحلية هي المسار الافتراضي ولا تتطلب اتصالًا خارجيًا.
- الخيار `ai_diagnose` معطّل افتراضيًا. عند تفعيله، قد ترسل مقتطفات أخطاء منقحة إلى endpoint الذي يحدده مسؤول المستودع في `ASHEN_AI_ENDPOINT`؛ التنقيح لا يضمن اكتشاف كل الأسرار.
- إن تطلب المزود مفتاحًا، خزّنه في GitHub Actions Secret باسم `ASHEN_AI_API_KEY` ولا تضعه في المصدر أو APK. لا يلزم إعداد مفتاح لتشغيل التشخيص المحلي.
- المساعد يقدّم فرضيات وخطوات تحقق فقط. لا يكتب ملفات المصدر، ولا يغيّر نتائج الاختبارات، ولا يصلح APK المثبّت تلقائيًا. يجب أن يراجع مطوّر التعديل، ويشغّل الاختبارات، ويبني APK جديدًا.
- درجة التشخيص ترتيب أولوية وليست احتمالًا إحصائيًا، ونتيجة «لا أخطاء معروفة» لا تعني أن اللعبة خالية من العيوب.

## حدود القبول

نجاح سير العمل يعني أن الاختبارات المحددة وبناء APK اجتازت شروط CI فقط. لا يثبت نجاح التثبيت أو الإدخال باللمس أو الأداء أو الحرارة أو استعادة الحفظ على جهاز حقيقي. قبل مشاركة الإصدار، اختبره على جهاز Android فعلي وسجّل طراز الجهاز وإصدار Android ونتيجة التثبيت والتشغيل والحفظ والقتال واللمس.

هذا إصدار **Debug/QA** للتجربة، وليس إصدارًا إنتاجيًا موقّعًا بمفتاح توزيع.
