> آخر تدقيق تحريري: 2026-10-19. يجرد هذا الملف وثائق Markdown الرئيسية ومصادر الحقيقة ذات الصلة. وجود الملف لا يعني أن الميزة التي يشرحها مكتملة. لا يُعد هذا سجلًا حيًا لنتائج CI؛ افحص نتائج رأس الفرع الحالي في [PR #24](https://github.com/areagleegy/AshenKingdoms/pull/24).

## قواعد القراءة

1. الكود والمشاهد وملفات الإعداد مصدر الحقيقة للسلوك المنفذ.
2. ملفات GitHub Actions مصدر الحقيقة للأوامر الآلية؛ صفحة التشغيل تحدد ما نجح على commit بعينه.
3. README يقدم ملخصًا، وdocs/README.md فهرسًا؛ تبقى تفاصيل النظام في وثيقته المتخصصة.
4. نطاق الإصدار يصف الهدف المعتمد، وحالة المشروع تلخص التنفيذ والقيود. لا يثبت أي منهما قبولًا يدويًا.
5. الخطط والمواصفات تسجل نية أو متطلبات تاريخية، ولا تُستخدم بدل الحالة الحالية.

## فروق يجب ألا تختفي

- **ENet مقابل WebSocket:** ENet هو الناقل الافتراضي لمساراته المدعومة، بينما WebSocket يوفر مسار عميل متوافقًا مع المتصفح. لا يستطيع المتصفح استضافة الخادم.
- **loopback مقابل خدمة منشورة:** اتصال عمليتين محليًا لا يثبت اتصال متصفح بخادم WSS منشور، أو صحة جدار الحماية، أو الأمان الإنتاجي.
- **التصدير مقابل القبول:** نجاح APK/Web export لا يثبت التشغيل على هاتف فعلي أو في المتصفح المستهدف.
- **32 مقابل 100 لاعب:** الحد الموثق 32 عميلًا؛ 100 لاعب هدف طويل الأمد لم يثبت باختبار حمل.
- **المجاني مقابل مفتوح الترخيص:** يجب تسجيل وقراءة الرخصة وإسنادها لكل أصل؛ رخصة الكود MIT لا تنطبق تلقائيًا على الأصول الخارجية.
- **حزم المحتوى:** توجد بنية أولية واختبارات، لكن تنزيل المحتوى الإنتاجي مؤجل ومعطل افتراضيًا.
- **نطاق PR:** ميزات WebSocket وباتل رويال قيد الاقتراح في [PR #24](https://github.com/areagleegy/AshenKingdoms/pull/24) وليستا جزءًا من main قبل الدمج.
