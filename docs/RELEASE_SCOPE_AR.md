# نطاق الإصدار المعتمد — ممالك الرماد

تاريخ اعتماد القرارات: 2026-10-19

## قرارات المنتج

- **نطاق اللعب المستهدف:** اللعب الفردي واللعب الجماعي.
- **المنصات المستهدفة:** Android وWeb.
- **الأصول:** إضافة أصول جديدة مجانية ومفتوحة الترخيص، مع توثيق المصدر والترخيص والإسناد قبل إدخال كل أصل إلى المستودع.
- **تنزيل حزم المحتوى:** مؤجل؛ يبقى التنزيل الإنتاجي معطلًا في هذا الإصدار.
- **سياسة الدمج:** لا دمج قبل مراجعة التغيير ونتائج فحوص CI المرتبطة بـ PR. لا تُسجّل الاختبارات كناجحة إلا عند وجود نتيجة فعلية.

## حدود الحالة الحالية

هذا الملف يحدد الهدف ولا يثبت اكتماله. وفق توثيق المشروع الحالي:

- اللعب الجماعي عبر ENet تجريبي، ولا توجد مصادقة إنتاجية أو حفظ شبكي دائم أو خادم عام مُدار.
- تصدير Web الحالي مخصص للعب الفردي ولا يدعم ENet.
- تصدير Android الحالي APK اختباري غير موقّع كتوزيع إنتاجي.
- سجل الأصول لا يثبت بعد اكتمال مجموعة فنية خارجية نهائية.

## بوابات الإصدار المطلوبة

### 1. اللعب الجماعي

- تحديد بنية نقل قابلة للعمل على كل منصة مستهدفة؛ لا يُفترض أن ENet يعمل داخل Web.
- توثيق دعم كل منصة بوضوح، بما في ذلك أي استثناءات مؤقتة.
- اختبار إنشاء الجلسة والانضمام والخروج وفقد الاتصال وإعادة الاتصال والتزامن والتحقق من صحة الرسائل.
- تحديد نموذج سلطة الخادم وحدود الثقة ومخاطر الغش قبل وصف اللعب الجماعي بأنه جاهز للإنتاج.
- عدم إتاحة استضافة عامة للإصدار الإنتاجي قبل معالجة المصادقة والأمان والمراقبة ومحدودية الموارد.

### 2. Android وWeb

- تشغيل فحوص التحقق والبناء على PR والتأكد من نجاحها قبل الدمج.
- اختبار APK على جهاز Android فعلي وتسجيل الجهاز وإصدار النظام ونتيجة سيناريوهات القبول.
- نشر تصدير Web على HTTP/HTTPS واختباره في المتصفحات والأحجام المستهدفة.
- لا يُعد نجاح التصدير وحده دليلًا على سلامة التشغيل الفعلي.

### 3. الأصول المجانية المفتوحة الترخيص

- لكل ملف خارجي: الاسم، والمؤلف، والرابط الأصلي، والرخصة ورابط نصها، والإسناد المطلوب، والسماح بالتعديل وإعادة التوزيع والاستخدام التجاري.
- الاحتفاظ بإثباتات الترخيص حيثما أمكن، وعدم إدخال أصول مجهولة الترخيص أو أصول لا تسمح شروطها بالتوزيع المقصود.
- تشغيل `python3 tools/validate_free_assets.py` ضمن التحقق ومراجعة السجل الناتج يدويًا.
- تفضيل أصول CC0 أو MIT أو CC BY الواضحة عند ملاءمتها، مع الالتزام الدقيق بشروط كل أصل وعدم افتراض أن كلمة «مجاني» تعني «مفتوح الترخيص».

### 4. حزم المحتوى

- تبقى ميزة تنزيل الحزم مؤجلة ومعطلة افتراضيًا.
- لا تُضمّن مفاتيح توقيع أو أسرار داخل المستودع أو ملفات البناء.
- تُفتح مهمة مستقلة قبل أي تفعيل لاحق، تشمل CDN وفهرسًا موثوقًا وتوقيعًا وإدارة إصدارات واختبارات فشل الشبكة والمساحة.

### 5. قرار الإصدار

لا يُعلن الإصدار جاهزًا إلا بعد توثيق:
- نتائج CI لكل PR مدمج ونتائج بناء Android/Web.
- نتائج اختبارات الجهاز والمتصفح الفعلية.
- حدود دعم اللعب الجماعي لكل منصة وأي استثناءات معتمدة.
- سجل الأصول وتراخيصها.
- آلية توقيع Android وقناة التوزيع وسياسة الإصدار.
- قرار قبول صريح مبني على الأدلة، لا على وجود ملفات البناء فقط.
