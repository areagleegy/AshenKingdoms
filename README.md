# ممالك الرماد | AshenKingdoms

مشروع لعبة تقمّص أدوار فانتازيا ثلاثية الأبعاد مفتوح المصدر باستخدام Godot 4.6 وGDScript. يستهدف Android وWeb أولًا، مع إبقاء توسعة الحاسوب وخادم لعب جماعي ضمن الخطة.

**الحالة الحالية:** نموذج أولي قابل للعب قيد التطوير. يتضمن حركة وقتالًا أساسيين، أعداء، صحة، جرد جرعات، خبرة ومستويات، مهمة تجريبية، وواجهة حفظ/تحميل. لا تزال الأصول الفنية والقصة الواسعة والمعدات المتقدمة واللعب الجماعي بحاجة إلى تطوير؛ نظام الحوار الحالي تجريبي.

## المنصات

- Android: بناء APK تجريبي لأجهزة ARM64.
- Web: ملفات HTML5 تُحفظ كـ Artifact ويمكن نشرها على استضافة ملفات ثابتة.
- Dedicated server: هيكل تمهيدي فقط؛ لا توجد استضافة لعب حي أو مزامنة شبكية مكتملة.

## التحكم

- الحركة: WASD أو الأسهم.
- القفز: Space، والركض: Shift.
- الهجوم: زر الفأرة الأيسر.
- الحقيبة: I أو Tab.
- الإيقاف: Esc.
- حفظ سريع: F5، تحميل سريع: F9.

ملف الحفظ المحلي هو user://savegame.json. على Android تظهر أزرار لمس للمناورة والقتال.

## حزم المحتوى الاختيارية

أُضيفت بنية أولية لمكتبة محتوى داخل اللعبة ومدير محتوى يقبل فهرسًا موقّعًا، وينزّل ZIP إلى مساحة التطبيق الخاصة، ويتحقق من SHA-256 وملفات الحزمة قبل التثبيت. الأصول الاختيارية لا تُحمّل إلى الذاكرة كلها دفعة واحدة؛ يمكن تحميل GLB وصوت من حزمة مثبتة.

**التنزيل الإنتاجي معطل افتراضيًا** لأن المستودع لا يحتوي على CDN أو فهرس حقيقي أو مفتاح توقيع إنتاجي. يجب إعداد ashen/content/catalog_url وashen/content/catalog_public_key في project.godot بعد نشر فهرس HTTPS موقّع. لا تضع المفتاح الخاص داخل المستودع أو APK. تفاصيل النشر وصيغة الحزم في content/README.md.

- مدير الحزم: scripts/content/
- مكتبة المحتوى: scenes/ui/ContentLibrary.tscn
- أداة إعداد ZIP وفهرس RSA-SHA256: tools/package_content.py؛ وتوقيع فهرس متعدد الحزم: tools/sign_content_catalog.py
- اختبارات الحزم: tests/content_catalog_smoke_test.gd وtools/test_package_content.py

هذه مرحلة تنفيذ أولية وليست تأكيدًا على اكتمال تجربة التنزيل على Android. استئناف التنزيل وفحص المساحة الحرة يحتاجان إلى استكمال، ويجب اختبار الأداء والتنزيل الفعلي على جهاز Android.

## العمل من الهاتف عبر Codespaces

1. افتح Code ثم Codespaces ثم Create codespace on main.
2. يثبت Dev Container أداة Godot CLI.
3. تحقق من المشروع من الطرفية:

   ~~~bash
   godot --headless --path . --editor --quit
   godot --headless --path . --script res://tests/gameplay_smoke_test.gd
   godot --headless --path . --script res://tests/content_catalog_smoke_test.gd
   python -m unittest tools.test_package_content tools.test_sign_content_catalog -v
   ~~~

4. استخدم Source Control ثم Commit وPush لحفظ التعديلات.

Codespaces مناسب لتحرير السكربتات والتوثيق والملفات النصية، لكنه ليس محرر Godot الرسومي داخل المتصفح.

## البناء الآلي

Workflow التحقق يعمل على main وعند Pull Request. Workflow البناء يصدر Android وWeb عند الدفع إلى main أو يدويًا من Actions.

- Artifact: ashen-kingdoms-web
- Artifact: ashen-kingdoms-android-debug
- إعدادات التصدير في export_presets.cfg.
- ملفات البناء مؤقتة، ولا يحتوي المشروع على مفاتيح توقيع.

## الحوار والشخصيات

اقترب من الشيخ المسافر واضغط E على الحاسوب أو زر «تحدّث» على الهاتف. يمكن قبول مهمة «اقتفاء الرماد»، وتُحفظ أعلام الحوار مع ملف الحفظ. نظام الحوار تجريبي ومحلي؛ التحقق الخادمي للتأثيرات لن يُفعّل إلا ضمن تطوير اللعب الجماعي.


## مسار الأصول البصرية والصوتية المجاني

يحتوي المشروع على أدوات محلية داخل محرر Godot لفحص نموذج اللاعب وتنظيم أصول الشخصيات والبيئات والخامات والموسيقى والمؤثرات والحوار العربي والفيديو. الفحص وإدارة السجل لا يحتاجان خدمة سحابية أو API مدفوعًا.

- دليل مسار الأصول: [docs/FREE_ASSET_PIPELINE_AR.md](docs/FREE_ASSET_PIPELINE_AR.md)
- دليل إضافة المحرر وربط نموذج اللاعب: [docs/PLUGIN_INTEGRATION_AR.md](docs/PLUGIN_INTEGRATION_AR.md)
- سجل التراخيص: [assets/asset_manifest.json](assets/asset_manifest.json)
- فحص السجل محليًا: `python3 tools/validate_free_assets.py`

هذه الدفعة تضيف الأدوات والبنية فقط؛ لم تضف نموذج GLB نهائيًا أو أصواتًا أو موسيقى مولّدة. أداة Meshy اختيارية وتتطلب مفتاحًا خارجيًا، ولا تعمل ضمن التحقق الآلي.


## اللعب الجماعي عبر ENet

تتضمن اللعبة ساحة شبكة تجريبية منفصلة مع جلسة ENet ومزامنة خادمية للحركة والصحة والهجمات والأعداء والتقدم الأولي بالمهمة. شغّل اللعبة من القائمة الرئيسية لاستضافة جلسة أو الانضمام إلى خادم على المنفذ الافتراضي 7777. نسخة Web تقتصر على اللعب الفردي لأن ENet غير متاح في إعداد التصدير الحالي.

هذه شريحة تقنية وليست خادم إنتاج: لا تتوفر حسابات أو حفظ شبكي دائم أو مزامنة كاملة للجرد والحوار، ويلزم اختبار جهازين فعليين وAndroid قبل اعتماد الشبكة للإصدار. راجع [docs/NETWORKING.md](docs/NETWORKING.md).
