# ممالك الرماد | AshenKingdoms

مشروع لعبة تقمّص أدوار فانتازيا ثلاثية الأبعاد مفتوح المصدر باستخدام Godot 4.6 وGDScript. يستهدف Android وWeb أولًا، مع تطوير اللعب الجماعي على مراحل.

**الحالة الحالية:** يحتوي المشروع على نموذج لعب فردي قابل للتجربة يشمل الحركة والقتال الأساسي والأعداء والصحة والجرد والخبرة والمستويات ومهمة تجريبية وحوارًا وحفظًا محليًا. توجد الآن أيضًا ساحة شبكة تجريبية مستقلة تعمل بـ ENet وتزامن اللاعبين والأعداء والحركة والصحة والهجمات والخبرة ومهمة قتل ثلاثية الأهداف عبر خادم authoritative. تظل الأصول الفنية والقصة الواسعة والمعدات المتقدمة ومزامنة الجرد والحوار والحفظ الدائم بحاجة إلى تطوير.

## المنصات

- Android: بناء APK تجريبي لأجهزة ARM64.
- Web: ملفات HTML5 تُحفظ كـ Artifact ويمكن نشرها على استضافة ملفات ثابتة؛ نسخة Web الحالية للعب الفردي.
- Desktop: تشغيل Godot لاختبار اللعب الفردي والاستضافة والانضمام.
- Dedicated server: خادم ENet تجريبي headless لساحة الشبكة على المنفذ الافتراضي 7777.

## التحكم في اللعب الفردي

- الحركة: WASD أو الأسهم.
- القفز: Space، والركض: Shift.
- الهجوم: زر الفأرة الأيسر.
- الحقيبة: I أو Tab.
- الإيقاف: Esc.
- حفظ سريع: F5، تحميل سريع: F9.

ملف الحفظ المحلي هو `user://savegame.json`. على Android تظهر أزرار لمس للحركة والقتال.

## تجربة الشبكة

تفتح اللعبة على القائمة الرئيسية:

- «اللعب الفردي» يفتح النموذج الأصلي.
- «استضافة جلسة على هذا الجهاز» يفتح ساحة الشبكة على المنفذ الافتراضي 7777.
- «الانضمام إلى الخادم» يتصل بعنوان IP أو اسم مضيف والمنفذ المحدد.

في ساحة الشبكة، يقرر الخادم حركة اللاعبين والضرر وصحة الأعداء والمكافآت. يستطيع اللاعب مهاجمة الأعداء، والحصول على الخبرة، وإكمال مهمة قتل ثلاثة أعداء مرة واحدة لكل شخصية في الجلسة. تُعرض الصحة والمستوى والخبرة وتقدم المهمة في الواجهة.

هذه مرحلة أولية وليست لعبة جماعية إنتاجية: لا توجد حسابات، أو حفظ دائم للحالة الشبكية، أو مزامنة للجرد والحوارات، ولا تحقق كامل ضد الغش. يجب اختبار الاتصال الحقيقي بين جهازين قبل قبول المرحلة نهائيًا. راجع [دليل الشبكة](docs/NETWORKING.md) و[خطة الاختبار](docs/TEST_PLAN.md).

لتشغيل الخادم المخصص بعد تثبيت Godot CLI 4.6:

~~~bash
godot --headless --path . -- --server --server-port=7777
~~~

العنوان `127.0.0.1` يشير إلى الجهاز نفسه، لا إلى جهاز آخر على الشبكة. لا تعرض هذه النسخة التجريبية مباشرة للإنترنت باعتبارها خادم إنتاج.

## العمل من الهاتف عبر Codespaces

1. افتح Code ثم Codespaces ثم Create codespace on main.
2. يثبت Dev Container أداة Godot CLI.
3. تحقق من المشروع من الطرفية:

   ~~~bash
   godot --headless --path . --editor --quit
   ~~~

4. استخدم Source Control ثم Commit وPush لحفظ التعديلات.

Codespaces مناسب لتحرير السكربتات والتوثيق والملفات النصية، لكنه ليس محرر Godot الرسومي داخل المتصفح.

## البناء الآلي

يعمل Workflow التحقق عند الدفع إلى `main` وعند Pull Request. ويصدّر Workflow البناء حزم Android وWeb عند الدفع إلى `main` أو يدويًا من Actions، كما يتحقق من التصدير عند Pull Request.

- Artifact: `ashen-kingdoms-web`
- Artifact: `ashen-kingdoms-android-debug`
- إعدادات التصدير في `export_presets.cfg`.
- ملفات البناء مؤقتة، ولا يحتوي المشروع على مفاتيح توقيع.

## الحوار والشخصيات

اقترب من الشيخ المسافر واضغط E على الحاسوب أو زر «تحدّث» على الهاتف. يمكن قبول مهمة «اقتفاء الرماد»، وتُحفظ أعلام الحوار ضمن الحفظ المحلي. نظام الحوار الحالي محلي؛ يجب نقل التحقق من آثار الحوار والجرد إلى الخادم قبل تفعيل مكافآت أو مهام مشتركة في الشبكة.
